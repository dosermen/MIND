# MIND — калибровочный лист черт (шаблон)

Локальный файл: скопируй в `docs/calibration.md` (gitignored) и заполни.
Назначение: стартовые `value` черт (0.0–1.0) из 20 развилок A/B/C;
дальше пересчёт только по реальным наблюдениям (правило пересчёта —
в конце реального листа / DESIGN).

Заполненный лист (ответы, грейды, итоговые value) — персональные данные:
**в git никогда не коммитить**, поэтому здесь только структура.

## Структура

1. **Развилки** — по одной на черту, три варианта:

   ```
   1. **rigor** — <ситуация>?
      A) <много черты> / B) <средне> / C) <мало черты>
   ```

   Разделы: `A. agent` (характер агента), `B. project` (характер
   стенда/проекта), `C. meta` (как работаем вместе).

2. **Строка ответов:** `1B 2C 3A ... 20C` (или ответы словами).

3. **Таблица полярности** — для каждой черты зафиксировать, что значит
   `value=1.0`, и заполнить для записи два поля:

   | черта | value=1.0 значит | direction | falsified_when |
   |---|---|---|---|
   | rigor | ... | «...» | наблюдение, опровергающее наклон |

4. **Грейды:** A → 0.8, B → 0.5, C → 0.2 (инвертировать там, где A =
   «меньше черты»); `confidence: 0.6` на старте.

5. **Итоговая таблица** (trait / scope / value) → из неё значения
   засеваются в `MIND/trait/*.md` через `remember`/`update`.
